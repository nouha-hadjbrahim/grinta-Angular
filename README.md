# GRINTA - Frontend (Angular)

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Mustapha-who/Grinta-angular.git
cd Grinta-angular
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
ng serve
```

Then open your browser at `http://localhost:4200`

> ⚠️ Make sure the Spring Boot backend is running on `http://localhost:8000` before using the app.
